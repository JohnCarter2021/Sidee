Sidee 0.2.0.0 is the first cross-platform beta: the catalogue-and-grid
dashboard from Phase 1, desktop packages for Windows, macOS and Linux
from Phase 2, the Android spike APK from Phase 3, and the Phase 4
polish (forget-this-TV, manual update check, bundled built-in icons,
plain-language errors, grid accessibility, per-platform docs).

### Beta status — please read before installing

- This is a **pre-release beta**, not a finished release. Builds are
  **unsigned**: Windows may show a SmartScreen warning and macOS may
  refuse to open the app until you allow an unverified app. Never
  disable SmartScreen or your antivirus to run Sidee.
- **Android pairing is not yet proven.** On the emulator the app
  starts and its loopback dashboard starts cleanly, but pairing a TV
  from the phone and installing a tile from the phone still need a TV
  test. Use the desktop dashboard as the proven path for now.
- In v1 Sidee pairs with **one TV at a time** (use "Forget this TV"
  in the dashboard to pair another). The native-install mode is not
  part of the v1 grid. The grid is a catalogue of tiles, not a
  guarantee that any particular web app will run well on any TV.

### Changes since 0.1.4.2

- Catalogue + grid dashboard: built-in apps (Nuvio, Stremio,
  Jellyfin) plus custom apps, installed state, search and category
  filters, per-card Install/Installed/Open.
- Desktop packages: Windows portable exe, macOS arm64 + x64 apps and
  DMGs, Linux x86_64 AppImage — all built and smoke-tested in CI.
- Android spike APK (Chaquopy + WebView, loopback dashboard only):
  builds in CI and starts cleanly on the emulator.
- Forget this TV: deletes only the saved pairing on the device.
- Manual update check in the dashboard footer: tells you a newer
  stable release exists, with a download link. It never downloads or
  installs anything by itself.
- Built-in icons bundled: dashboard cards no longer depend on remote
  icon URLs, and a broken card icon removes itself instead of
  breaking the card. Jellyfin's TV tile icon now points at this fork.
- Plain-language errors: discovery failures no longer leak raw
  exceptions, expiry messages no longer mention tokens, and the
  no-TV message points at the manual IP option.
- Grid accessibility: screen-reader-friendly Remove buttons, search
  result counts announced through the status region, focus-visible
  outlines, reduced-motion and high-contrast support.
- Linux network discovery fix (interface broadcast calculation) and
  the AppImage smoke-test exemptions it needed.
- Per-platform README, beta report template, and trademark/icon note.

### Install

- **Windows:** extract the exe ZIP and run it. Keep its window open
  while using the dashboard.
- **macOS:** open the DMG for your architecture, drag Sidee.app to
  Applications, and use **Open dashboard** in its control window.
  Unsigned: follow Apple's instructions for opening an unverified
  app, and grant local network access.
- **Linux:** make the AppImage executable and run it. Ubuntu LTS is
  the primary tested distro.
- **Android:** sideload the APK and allow installing from this
  source when asked. See the beta limit above.

Find your TV, request a code, enter the four-digit PIN shown on the
TV, then install from the grid. Keep dashboard links, PINs and saved
pairing tokens private, and never include them in a bug report.
Report beta problems with TV model, firmware, platform and build,
and the redacted diagnostic log from "Check my setup".
